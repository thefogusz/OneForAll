### งานง่ายไม่ต้องค้นเพิ่ม

ให้ผู้ช่วยทดสอบอ่านสกิลรุ่นปัจจุบันและทำคำขอแก้หัวข้อหน้าเว็บ โดยไม่ได้บอกผลลัพธ์การเลือกเส้นทางที่คาดหวังไว้ล่วงหน้า ผู้ช่วยเลือกแก้ไฟล์โดยตรง เปลี่ยนเพียงหนึ่งคำ ไม่ใช้เครื่องมือค้นภายนอกและไม่สร้างไฟล์เพิ่ม มีการแจ้งใช้สกิลครั้งแรกตามข้อกำหนดของ host; OneForAll ไม่ได้เพิ่มรายงานรีเสิร์ชหรือคำแนะนำที่ไม่จำเป็น

นี่เป็นตัวอย่างการรันหนึ่งครั้ง ไม่ใช่หลักฐานว่าจะเงียบถูกจังหวะทุกคำขอหรือทุกโมเดล

### รายละเอียดสองโจทย์จากเวอร์ชันก่อนหน้า

**Atlas Contacts:** input มีชื่อไทย comma, double quotes, newline และช่องว่างเปล่า ตัว export เดิมใช้ string join ทำให้ round-trip test ล้มเหลว ผู้ช่วยเปลี่ยนไปใช้ `csv.writer` และสร้างสกิลเฉพาะโปรเจกต์ เทสต์เดิมผ่านหลังแก้

**Beacon Inventory:** แยกไปอีกโปรเจกต์ที่กำหนด TSV, UTF-8 ไม่มี BOM และ LF record endings ผู้ช่วยอ่านเงื่อนไขใหม่ ใช้ตัวเขียนที่กำหนด dialect ของโปรเจกต์นี้ และสร้างอีกสกิลหนึ่ง เทสต์ round-trip กับ byte assertions ผ่าน

ทดสอบบน Python 3.11.9 โปรเจกต์ละหนึ่งเทสต์ ผลเหล่านี้ยืนยันตัวอย่างที่รัน ไม่ใช่คะแนนรับประกันการเรียกสกิลของโมเดล

### การติดตั้งที่ทดลอง

รันในโฟลเดอร์ทดสอบว่าง โดยชี้ไปยัง clone ที่เตรียมเผยแพร่:

```sh
npx skills add /path/to/OneForAll --skill oneforall --agent codex claude-code --copy --yes
```

`/path/to/OneForAll` เป็น placeholder ให้แทนด้วย clone ของผู้ทดสอบ คำสั่งไม่ใช้ `--global` จึงไม่ติดตั้งชุดทดสอบทับสกิลส่วนตัว พบสองสกิลใน repo และเลือกติดตั้งเฉพาะ `oneforall` ตามที่ระบุ

การตรวจการวางไฟล์ไม่ทดแทนการเปิด Codex/Claude Code ใหม่แล้วทำงานจริง และการรีเสิร์ชในโมเดลอาจให้ผลต่างกันระหว่างการรัน

## ทดสอบพฤติกรรมรอบถัดไป

โจทย์ด้านล่างเป็น **แผนทดสอบ** ไม่ใช่ผลที่อ้างว่าผ่านแล้ว:

0. **ทดสอบการเลือกเส้นทางให้กว้างขึ้น:** งานที่มีสกิลเดิมครอบคลุม คำถามความคืบหน้า และโจทย์ใหม่ที่มีประโยชน์จากสกิลเฉพาะทาง ต้องแยกการใช้ของเดิมกับการค้นเพิ่มได้ถูกจังหวะ
1. **สลับ host ในโปรเจกต์เดียวกัน:** ให้ Codex สร้างสกิล จากนั้นเปิด Claude Code แล้วทำโจทย์คล้ายกัน ควรอ่านไฟล์เดิมและไม่สร้างซ้ำใน `.claude/skills/`
2. **คำแนะนำต้องไม่ขวางงาน:** ใช้โปรเจกต์ที่ขาดสกิลภายนอกจริง ให้เสนอทางเลือกแต่ยังทำงานหลักต่อ โดยไม่ติดตั้งสิ่งที่ไม่ได้เลือก
3. **แก้ของเดิม:** ให้โจทย์ที่เผยข้อบกพร่องของสกิลที่จัดการอยู่ ควรอัปเดตไฟล์เดิม โดยรักษาสิ่งที่ยังถูกต้อง
4. **อ่านอย่างเดียวหรือ offline:** ระบุข้อจำกัดตรง ๆ ต้องไม่เขียนไฟล์หรืออ้างว่าค้นเว็บแล้ว
5. **symlink/junction ออกนอกโปรเจกต์:** ชี้โฟลเดอร์สกิลออกไปนอก checkout ต้องไม่เขียนผ่านเส้นทางนั้น
6. **หลายแชตแก้ไฟล์เดียวกัน:** ตรวจการอ่านไฟล์ล่าสุดและรักษาการเปลี่ยนแปลงของอีกแชต ก่อนอ้างว่ารองรับการทำงานพร้อมกัน

## ข้อจำกัดที่มีผลกับการใช้จริง

OneForAll เป็นคำสั่งสำหรับ agent การแยกโปรเจกต์และการเรียกอัตโนมัติจึงต้องอาศัย agent ปฏิบัติตาม รวมถึงสิทธิ์และ sandbox ของ host มันไม่ได้เพิ่มระบบบังคับสิทธิ์หรือดักข้อความทุกครั้ง

หากพบความผิดพลาด ให้รายงานพร้อมโจทย์ เวอร์ชัน agent และหลักฐานที่ลบข้อมูลส่วนตัวแล้ว พฤติกรรมที่ทำซ้ำได้ช่วยแก้สกิลได้ดีกว่าคำว่า “มันเอ๋อ” ถึงแม้บางวันคำหลังจะตรงความรู้สึกที่สุดก็ตาม
