## งานแก้คำผิด

ให้ agent อีกตัวอ่าน OneForAll รุ่นปัจจุบัน แล้วแก้ `Welcom` เป็น `Welcome` ในหัวข้อของหน้า HTML โดยไม่ได้บอกล่วงหน้าว่าควรเลือกขั้นตอนใด

Agent แก้เพียงหนึ่งคำและอ่านไฟล์ยืนยันหลังแก้ ไม่มีการค้นภายนอกหรือสร้างไฟล์เพิ่ม มีการแจ้งใช้สกิลครั้งแรกตามข้อกำหนดของระบบที่รันทดสอบ แต่ไม่มีรายงานรีเสิร์ชหรือข้อเสนอให้ติดตั้งสกิล

ผลนี้เป็นการทดลองหนึ่งครั้ง จึงยังต้องทดสอบกับคำขอประเภทอื่นเพิ่มเติม

## การแยกความรู้ระหว่างโปรเจกต์

สองกรณีนี้ทดสอบกับรุ่นก่อนเพิ่มการปรับตาม agent และก่อนเปลี่ยนเป็นการรีเสิร์ชแบบมีเงื่อนไข จึงใช้เป็นหลักฐานของการแก้ปัญหาและการเก็บสกิลแยกโปรเจกต์ ไม่ได้ใช้ยืนยันการเลือกจังหวะค้นของรุ่นปัจจุบัน

**Atlas Contacts — CSV:** ข้อมูลมีภาษาไทย comma, double quotes, newline และช่องว่างเปล่า โค้ดเดิมใช้ string join ทำให้เทสต์อ่านข้อมูลกลับแล้วได้ผลไม่ตรงกัน หลังเปลี่ยนเป็น `csv.writer` เทสต์เดิมผ่าน และมีสกิล `atlas-contacts-csv-export` อยู่ในโปรเจกต์

**Beacon Inventory — TSV:** โปรเจกต์นี้กำหนดให้ใช้ tab, UTF-8 ไม่มี BOM และ LF เป็นตัวจบบรรทัด Agent อ่านข้อกำหนดใหม่ ตั้งค่าการเขียนให้ตรง แล้วสร้างสกิล `beacon-inventory-tsv-export` แยกไว้ เทสต์อ่านข้อมูลกลับและตรวจไบต์ผ่าน

ทั้งสองกรณีค้นเอกสาร Python และค้นสกิลแยกกัน มีการบันทึกแหล่งที่เข้าถึงไม่ได้ตามจริง สกิลที่สร้างผ่านตัวตรวจรูปแบบ และเทสต์ทั้งสองโปรเจกต์ผ่านเมื่อรันซ้ำบน Python 3.11.9 โปรเจกต์ละหนึ่งเทสต์

## การติดตั้ง

ทดลองในโฟลเดอร์แยก โดยติดตั้งจาก clone ที่เตรียมเผยแพร่:

```sh
npx skills add /path/to/OneForAll --skill oneforall --agent codex claude-code --copy --yes
```

`/path/to/OneForAll` ให้แทนด้วยตำแหน่ง clone บนเครื่องที่ทดสอบ คำสั่งนี้ไม่ใช้ `--global` จึงไม่ทับสกิลส่วนตัว

ตัวติดตั้งพบสองสกิลใน repo และเลือกเฉพาะ `oneforall` ตามคำสั่ง จากนั้นคัดลอกลง `.agents/skills/oneforall/` และ `.claude/skills/oneforall/` เมื่อตรวจชื่อไฟล์และ hash พบว่าตรงกับแพ็กเกจต้นฉบับ

การตรวจนี้ครอบคลุมการวางไฟล์ ยังไม่ใช่การเปิด Claude Code แล้วทดลองทำงานจริง

## สิ่งที่ยังต้องทดสอบ

รายการต่อไปนี้ยังไม่มีผลทดสอบ:

1. การเลือกใช้ของเดิมหรือค้นเพิ่มในคำขอที่หลากหลาย รวมถึงการถามความคืบหน้าและงานที่มีสกิลครอบคลุมอยู่แล้ว
2. การสลับจาก Codex ไป Claude Code แล้วใช้สกิลเดิมโดยไม่สร้างซ้ำ
3. การเสนอให้ติดตั้งสกิลภายนอกพร้อมทำงานหลักต่อ โดยไม่ติดตั้งก่อนผู้ใช้เลือก
4. การปรับสกิลเดิมเมื่อพบวิธีที่ใช้ไม่ได้ โดยรักษาส่วนที่ยังถูกต้อง
5. การทำตามข้อจำกัดให้อ่านอย่างเดียวหรือทำงาน offline
6. การจัดการ symlink/junction ที่ชี้ออกนอกโปรเจกต์
7. การรักษาการเปลี่ยนแปลงเมื่อหลายแชตแก้ไฟล์เดียวกัน

## ข้อจำกัด

OneForAll เป็นคำสั่งให้ agent ปฏิบัติตาม พฤติกรรมจึงอาจต่างกันตามโมเดล เครื่องมือ และการตั้งค่าของระบบ ส่วนการบังคับสิทธิ์ยังเป็นหน้าที่ของ agent และ sandbox ที่ใช้อยู่

หากพบปัญหา สามารถ [เปิด issue](https://github.com/thefogusz/OneForAll/issues) พร้อมคำขอที่ใช้ เวอร์ชัน agent และผลที่เกิดขึ้น โดยลบข้อมูลส่วนตัวออกก่อน
